## 2. QUÉ DATOS RECOPILAMOS

### 2.1 Datos Personales
| Dato | Propósito | Retención |
|------|-----------|-----------|
| Nombre completo | Crear cuenta | Mientras activa cuenta |
| Email | Comunicación | Mientras activa cuenta |
| Número celular (opcional) | Alertas SMS | Mientras activa cuenta |
| Empresa/Firma | Contexto auditoría | Mientras activa cuenta |
| Contraseña (hasheada) | Autenticación | Mientras activa cuenta |

### 2.2 Datos de Auditoría
| Dato | Propósito | Retención |
|------|-----------|-----------|
| Estados financieros | Análisis de auditoría | 2 años (según normas) |
| Reportes generados | Auditoría interna | 2 años |
| Hallazgos documentados | Historial cliente | 2 años |
| Logs de acceso | Seguridad/auditoría | 1 año |

### 2.3 Datos Técnicos
| Dato | Propósito | Retención |
|------|-----------|-----------|
| Dirección IP | Seguridad | 90 días |
| Navegador/SO | Soporte técnico | 90 días |
| Historial de clicks | Mejorar UX | 6 meses |
| Errores/crashes | Debugging | 30 días |

### 2.4 Datos de Pago (si aplica)
- **NO** almacenamos tarjetas (procesador externo)
- Empresa: nombre, dirección, RUC
- Historial: facturas, fechas, montos

## 3. CÓMO USAMOS TUS DATOS

### 3.1 Usos Permitidos
✓ Proporcionar el servicio  
✓ Mejorar features/seguridad  
✓ Cumplir obligaciones legales  
✓ Detectar fraude  
✓ Enviar actualizaciones importantes  
✓ Estadísticas anónimas  

### 3.2 Usos NO Permitidos
✗ Vender a terceros  
✗ Marketing sin consentimiento  
✗ Entrenar IA con datos de clientes  
✗ Compartir con competidores  
✗ Usar para fines políticos/religiosos  
✗ Crear perfiles de riesgo crediticio

## 4. COMPARTIR DATOS

### 4.1 Con Quién Compartimos
| Tercero | Propósito | Datos | Protección |
|---------|-----------|-------|-----------|
| Google Drive | Guardar pruebas | URLs firmadas | Encriptación E2E |
| Power BI | Reportes ejecutivos | Resúmenes anónimos | Encriptación |
| Proveedores cloud | Almacenamiento | Data encriptada | Contrato DPA |
| Autoridades (si requerido) | Cumplimiento legal | Según orden judicial | Mínimo necesario |

### 4.2 Con Quién NO Compartimos
✗ Agencias de publicidad  
✗ Brokers de datos  
✗ Competidores  
✗ Terceros sin consentimiento

## 5. SEGURIDAD

### 5.1 Medidas Implementadas
- ✓ Encriptación AES-256 en reposo
- ✓ HTTPS TLS 1.3 en tránsito
- ✓ Hashing bcrypt para contraseñas
- ✓ Autenticación JWT con expiración 30 min
- ✓ Backups diarios con versioning
- ✓ Monitoreo de acceso anómalo
- ✓ Firewall y WAF activo

### 5.2 Lo Que NO Podemos Garantizar
- ✗ Seguridad 100% (riesgo cibernético existe)
- ✗ Protección contra ataques sofisticados
- ✗ Que no haya breaches nunca

**Si hay incidente:** Notificamos en 48 horas
