# TÉRMINOS DE SERVICIO - SOCIOAI

**Última actualización:** 16 de mayo de 2026  
**Jurisdicción:** Ecuador (Ley de Comercio Electrónico)

---

## 1. DEFINICIONES Y ALCANCE

### 1.1 El Servicio
SocioAI es una plataforma web de asistencia en auditoría financiera que utiliza inteligencia artificial para:
- Analizar estados financieros
- Calcular materialidad según NIAs
- Identificar áreas de riesgo
- Generar recomendaciones técnicas
- Automatizar documentación de auditoría

### 1.2 Naturaleza del Servicio
**SocioAI es una HERRAMIENTA ASISTENTE, NO un reemplazo de auditoría profesional.**

El usuario reconoce que:
- ✓ SocioAI provee recomendaciones basadas en análisis
- ✓ El usuario (auditor) es responsable de todas las decisiones técnicas
- ✓ El análisis de IA es complementario, no definitivo
- ✓ La auditoría final depende del juicio profesional del auditor

---

## 2. RESPONSABILIDADES DEL USUARIO

### 2.1 Usuario Debe
- ✓ Ser profesional contable/auditor registrado
- ✓ Verificar toda recomendación de SocioAI antes de usarla
- ✓ Mantener confidencialidad de datos de clientes
- ✓ Cumplir NIAs, Código de Ética Profesional
- ✓ Documentar todas las decisiones técnicas tomadas
- ✓ No usar información para fines distintos a auditoría

### 2.2 Usuario NO Debe
- ✗ Usar análisis de SocioAI como auditoría final
- ✗ Compartir accesos con personas no autorizadas
- ✗ Modificar o falsificar reportes generados
- ✗ Usar para fines distintos a auditoría
- ✗ Revelar información confidencial de clientes
- ✗ Hacer ingeniería inversa del sistema

---

## 3. RESPONSABILIDADES DE SOCIOAI

### 3.1 SocioAI Proporciona
- ✓ Herramienta estable con uptime 99%
- ✓ Encriptación de datos
- ✓ Backups automáticos diarios
- ✓ Actualizaciones de normativa (NIAs, NIIFs)
- ✓ Soporte técnico por email

### 3.2 SocioAI NO Garantiza
- ✗ Que análisis sea 100% exacto (puede haber errores de IA)
- ✗ Validez legal de documentos generados
- ✗ Que recomendaciones sean aceptadas por reguladores
- ✗ Responsabilidad por decisiones del auditor basadas en SocioAI

### 3.3 Limitación de Responsabilidad
**SocioAI no es responsable por:**
- Daños directos o indirectos derivados del uso
- Pérdida de datos (aunque aplicamos medidas razonables)
- Interpretación incorrecta de recomendaciones
- Decisiones del usuario basadas en análisis de SocioAI
- Problemas de conexión o disponibilidad

**Responsabilidad máxima:** Reembolso de 1 mes de suscripción

### 4.1 Datos Que Recopilamos
- Email, nombre, empresa
- Datos financieros cargados
- Historial de auditorías
- Logs de actividad
- Información de facturación

### 4.2 Cómo Usamos Datos
- ✓ Mejorar la plataforma
- ✓ Detectar fraude/uso indebido
- ✓ Cumplir obligaciones legales
- ✓ Enviar actualizaciones normativas

### 4.3 Datos NO Usamos
- ✗ Vendemos a terceros

- ✗ Compartimos sin consentimiento
